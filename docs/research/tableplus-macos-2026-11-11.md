# Catatan perilaku TablePlus di macOS · 11 November 2026

TablePlus **27.2.0 build 840** edisi uji coba di macOS **27.2 (26B123)**, dengan SQLite **3.53.1** dari aplikasi. Saya memakai profil `TablePlus Behavior Lab 2026-11-11` dan salinan lokal dari [seed SQLite Tabler](../../dev/seed/sqlite/seed.sql). CLI SQLite membaca file yang sama dari proses terpisah untuk memeriksa efek perubahan. Salinan Tabler dibuat dari seed yang sama. Tabler native belum dijalankan karena binary dan toolchain Rust tidak tersedia di lingkungan pengujian ini.

ID merujuk ke [skenario evaluasi](tableplus-behavior-scenarios.md). Baris berstatus **diamati** mencatat langkah yang benar-benar dijalankan, termasuk apabila langkah tersebut baru mencakup sebagian skenario. Semua hasil perbandingan native Tabler masih **belum dibandingkan**.

## Perubahan versi yang perlu dievaluasi

- **Welcome, Sync Database, dan Schedule Tasks.** Welcome menampilkan tombol `Sync database` serta bagian `Backups` dengan tooltip tentang tugas backup, restore, dan sync terjadwal. Alur konfigurasi, eksekusi, dan pemulihan masih perlu diuji melalui `IO-05` dan `IO-06`. Catatan rilis menempatkan perubahan ini di macOS build 840 dan Windows build 412. [Catatan rilis macOS](https://tableplus.com/osx/changelog) · [Catatan rilis Windows](https://tableplus.com/win/changelog)
- **Jump to Columns.** `⌘L` membuka pencarian kolom pada grid macOS saat diuji. Checklist lama mencatat `⌘L` untuk plugin. Catatan rilis Windows menyebut `Ctrl+L`. Ulangi dari fokus editor SQL dan launcher sebelum menetapkan perilaku lintas konteks. [Catatan rilis macOS](https://tableplus.com/osx/changelog) · [Catatan rilis Windows](https://tableplus.com/win/changelog) · [Checklist historis](tableplus-functional-spec.md)
- **Urutan kolom CSV.** TablePlus macOS mempertahankan urutan kolom query pada percobaan `IO-01`. Implementasi Tabler menyusun hasil sesuai urutan field yang dimasukkan, sebagaimana perubahan berbasis rekaman Windows pada commit `102afea`. Ulangi dengan input dan hasil yang sama pada kedua platform sebelum menetapkan perilaku Tabler. [Implementasi pemilihan field](../../src/features/export/options.ts) · [Tes dialog ekspor](../../src/features/export/ExportDialog.test.tsx) · [Commit Tabler](https://github.com/kungfufafa/tabler/commit/102afea0a01fdcfe548d18a4ddc795af7cf166e4)
- **Impor profil TablePlus.** Ini celah migrasi berdasarkan inspeksi implementasi Tabler. Pemilih menerima `.tablerconnections`, dan parser memvalidasi format `tabler-connections`. Jalur impor URL sudah tersedia, dengan sebagian nilai TLS dari TablePlus ditafsirkan lewat pemetaan heuristik. Uji `MIG-01` memakai grup dan profil sintetis untuk mengetahui atribut yang ikut pindah. [Pemilih impor](../../src/features/connections/ioStore.ts) · [Parser](../../src-tauri/src/profiles_io.rs) · [Pemetaan URL](../../src/features/connections/url.ts)

## Baseline Tabler dan urutan evaluasi

Checkout Tabler berbasis `102afea` dengan perubahan lokal yang sudah ada. Pada 14 suite frontend terpilih, **449 tes lulus** saat dijalankan ulang dengan dua worker. Percobaan pertama sempat gagal pada kasus `Escape` di dialog Safe Mode saat mematikan read-only. Kasus tersebut lulus saat diisolasi, saat seluruh file diuji ulang, dan saat 14 suite dijalankan ulang. Dua suite ekspor juga lulus pada pengujian terpisah, dengan 98 tes. Perlu reproduksi native sebelum menyimpulkan ada selisih perilaku. [Tes dialog koneksi](../../src/features/connections/ConnectionDialog.test.tsx)

1. Jalankan skenario `P0` pada kedua aplikasi native dengan dua salinan fixture. Dahulukan fokus dan seleksi (`NAV-01`, `GRID-01`, `GRID-02`), batas perubahan (`EDIT-01`–`EDIT-04`), cakupan dan pembatalan SQL (`SQL-01`–`SQL-03`), serta read-only (`SAFE-02`). Selisih pada aksi yang bisa menulis data perlu bukti pembacaan dari sesi terpisah.
2. Ulangi skenario yang bergantung pada server di PostgreSQL dan MySQL/MariaDB. Commit workspace Tabler memiliki jalur untuk operasi transaksional dan DDL yang dapat diterapkan sebagian, sehingga catat DML, DDL, hasil yang tersimpan, serta draft yang dapat diperbaiki. Ulangi navigasi, shortcut, dan dialog file pada Windows. [Implementasi commit workspace](../../src-tauri/src/commands/workspace_commit.rs) · [Catatan historis Windows](../tableplus-parity.md#windows-observation-3-november-2026-)
3. Ukur dampak migrasi koneksi dan alur 27.2 secara terpisah. Gunakan [spesifikasi publik](tableplus-functional-spec.md) untuk menelusuri skenario tambahan. Sumber vendor merinci [alur commit](https://tableplus.com/docs/gui-tools/code-review-and-safemode/commit-changes), [filter](https://tableplus.com/docs/gui-tools/filter), dan [navigasi tab](https://tableplus.com/docs/gui-tools/the-interface/multi-tabs-workspaces-windows).
