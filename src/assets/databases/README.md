# Database logos

These assets ship with the renderer and work offline.

- Most SVGs: [Simple Icons v11.15.0](https://github.com/simple-icons/simple-icons/tree/v11.15.0), CC0. DuckDB and any icons absent in that release use the `develop` collection downloaded on 2026-11-03.
- SQL Server: [Devicon](https://github.com/devicons/devicon), MIT.
- Greenplum, Vertica, DynamoDB and Redshift: [DBeaver](https://github.com/dbeaver/dbeaver/tree/devel/plugins), Apache-2.0. Original paths are `org.jkiss.dbeaver.ext.greenplum/icons/greenplum_icon_big@2x.png`, `org.jkiss.dbeaver.ext.vertica/icons/vertica_icon_big@2x.png`, `org.jkiss.dbeaver.ext.generic/icons/dynamodb_pro_icon@2x.png`, and `org.jkiss.dbeaver.ext.postgresql/icons/redshift_icon.svg`.

D1 uses the Cloudflare logo; LibSQL uses the Turso logo. Logos remain trademarks of their respective owners. All assets render as alpha masks with a contrasting foreground on an opaque connection-tinted background. Light and dark themes use separate backgrounds; icon contrast exceeds 4.5:1.
